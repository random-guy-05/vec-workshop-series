# VEC Multilingual Peer Workshop Series

Self-contained, low-barrier workshop guides for groups learning the Virtual Embryo Challenge together. Each edition includes a timed facilitator plan, fictional exercise, participant prompts, and an answer key. No challenge data, account, code, or software installation is needed.

## Sessions

- [English first-workflow kit](https://github.com/random-guy-05/vec-workshop-kit) — find a resource, interpret evidence, screen a data proposal, and plan a reproducible run. Translations in this repository: Spanish, Simplified Chinese, French, Hindi, Japanese, Korean, Brazilian Portuguese, Arabic, German, Italian, and Turkish.
- [`t1-temporal/en`](workshops/t1-temporal/en.md) — reason about temporal gene-expression distributions, changing cell-state mixtures, and the limits of pseudobulk summaries. Translations: German, Italian, Turkish, Spanish, Simplified Chinese, French, Japanese, Korean, and Brazilian Portuguese.
- [`t2-spatial/en`](workshops/t2-spatial/en.md) — reason about Task 2's interpolation and extrapolation settings, three prediction scales, and per-embryo coordinate frames. Translations: Spanish, Simplified Chinese, French, Japanese, Korean, Brazilian Portuguese, German, Italian, and Turkish.
- [`t3-perturbation/en`](workshops/t3-perturbation/en.md) — reason about matched wild-type references, perturbation response, and held-out conditions. Translations: Spanish, Simplified Chinese, French, Japanese, Korean, Brazilian Portuguese, German, Italian, and Turkish.

## Use

Open the edition for your language, follow its timing, and share the worksheet prompts. Exercises use fictional scenarios. For current challenge facts, use the official pages linked from each guide; they take precedence over this workshop material. The translations preserve board IDs, gene symbols, units, and URLs. Machine-assisted first editions are explicitly open to native-speaker corrections by pull request.

These are independent community workshop materials, not official events or endorsements. Each guide may be used and adapted under the MIT license.

## Translation and update policy

English is the canonical factual source. Before every workshop, verify the official Challenge links. When a task split, metric, or rule changes, update the English guide first, then every translation. Keep code identifiers, board IDs, gene symbols, and URLs literal. Please open a correction issue or pull request if a translation is unclear or a linked fact has changed.
