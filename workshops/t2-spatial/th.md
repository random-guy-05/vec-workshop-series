# เวิร์กช็อป Task 2: ให้เหตุผลข้ามมิติของพื้นที่และเวลา

**75 นาที · ผู้เข้าร่วม 4–20 คน · ไม่ต้องใช้โค้ดหรือข้อมูล Challenge**

เซสชันพร้อมแผนสำหรับผู้นำนี้เหมาะกับผู้ที่รู้แนวคิด single-cell พื้นฐานแต่เพิ่งเริ่มการพยากรณ์เชิงพื้นที่-เวลาสามมิติ ใช้การเปรียบเทียบแบบจำลองสมมติ เป้าหมายคือให้คิดเรื่องข้อกำหนดของ Task และหลักฐาน ไม่ใช่สอนสูตรสร้างแบบจำลองที่ยังไม่ได้ตรวจสอบ

> ฉบับแปลแรกนี้ใช้เครื่องมือช่วยแปลและเปิดรับการแก้ไขจากเจ้าของภาษา [ต้นฉบับภาษาอังกฤษ](en.md)

## เตรียมการ

เปิดหน้าอย่างเป็นทางการเกี่ยวกับ[คำอธิบาย Task](https://virtualembryo.ai/challenge/tasks), [schema ข้อมูล](https://virtualembryo.ai/challenge/data), และ[การประเมิน](https://virtualembryo.ai/challenge/evaluation) เตรียมกระดาษหรือแชร์คู่มือนี้ ขอให้ผู้เข้าร่วมไม่ใช้ hidden target และไม่แชร์ผลแบบจำลองส่วนตัว ตรวจสอบหน้าอย่างเป็นทางการอีกครั้งก่อนจัดกิจกรรม เพราะเป็นแหล่งข้อมูลที่มีอำนาจอ้างอิง

## แบบฝึกหัด 1 — Task เดียว แต่มี setting ต่างกัน

ทีม “Small Atlas” สมมติคิดว่า board ทุกชุดของ Task 2 ต้องพยากรณ์ไกลเกิน stage ล่าสุดใน training ให้แต่ละคู่ดูตาราง split อย่างเป็นทางการและแก้ความเข้าใจนี้ พวกเขาควรระบุ held-out interpolation ของ setting whole-embryo แล้วเปรียบเทียบกับคำถาม interpolation และ extrapolation ใน setting heart ถามว่าอะไรเหมือนและต่างกัน: ทั้งสองพยากรณ์ expression และพิกัด 3D แต่ setting และการแบ่ง stage ต่างกัน

### เฉลย

Task 2 มีสอง setting การทดสอบ whole-embryo เป็น interpolation: stage ที่กันไว้อยู่ระหว่าง stage ที่เผยแพร่แล้ว ใน setting heart คำถาม validation ที่กันไว้ข้อหนึ่งเป็น interpolation ส่วน stage ที่ตามมาทดสอบ extrapolation ออกนอกช่วง training ที่เผยแพร่แล้ว ให้ตรวจชื่อ stage และ board ID ที่แน่นอนจากหน้าอย่างเป็นทางการปัจจุบัน ไม่ใช้ความจำ

## แบบฝึกหัด 2 — คำถามสี่ข้อที่ให้น้ำหนักเท่ากัน

Model A สมมติทำนายการเปลี่ยนแปลงของ expression ได้พอใช้ แต่คาดการณ์กลุ่มเซลล์ที่กระจายสม่ำเสมอ Model B มีรูปร่างและ neighborhood เฉพาะที่สมเหตุสมผล แต่การเปลี่ยน expression อ่อน ทั้งสองยังไม่ได้รับคะแนนอย่างเป็นทางการ ถามแต่ละคู่: หลักฐานใดแยกประสิทธิภาพ molecular, cellular, tissue และ local organization ได้? local pseudo-split พิสูจน์อะไรได้ และพิสูจน์อะไรเกี่ยวกับ hidden board ไม่ได้?

### เฉลย

คะแนน T2 อย่างเป็นทางการให้น้ำหนักหนึ่งในสี่แก่แต่ละด้าน ได้แก่ expression change, cell-state distribution, tissue shape/growth scale และ local spatial organization ผลดีด้านหนึ่งไม่ได้พิสูจน์ว่าด้านอื่นดีด้วย การเปรียบเทียบในพื้นที่บอกได้เฉพาะข้อมูล split และ scorer ที่เลือก ไม่ใช่ผล hidden test

## แบบฝึกหัด 3 — ตรวจสอบ coordinate frame

มี point cloud 3D สำหรับสอง stage สมมติ เพื่อนร่วมทีมจับคู่เซลล์ที่มีค่า `(x,y,z)` เชิงตัวเลขเท่ากันข้าม stage และเรียกว่าเป็นเซลล์เดียวกัน ถามว่าต้องมีหลักฐานอะไรจึงจะรองรับข้อกล่าวอ้างเรื่องอัตลักษณ์นี้?

### เฉลย

ไม่มีหลักฐานจากค่าพิกัดเพียงอย่างเดียว หน้า data อย่างเป็นทางการระบุว่าพิกัดใช้ local frame แยกกันในแต่ละ embryo และไม่ได้ register ข้าม time point อย่าอนุมานการจับคู่เซลล์ข้าม stage หรือ coordinate frame ร่วมกันจากตัวเลขที่ตรงกัน อ่าน schema อย่างเป็นทางการก่อนตั้งสมมติฐานเรื่อง registration ในการวิเคราะห์

## ใบงานผู้เข้าร่วม

1. สำหรับ board ที่เลือก ให้ระบุ training stage ที่มองเห็น, คำถาม held-out และช่องข้อมูลที่ต้องพยากรณ์ พร้อมอ้างหน้าอย่างเป็นทางการปัจจุบัน
2. สำหรับคะแนนที่รายงาน ให้จด split, scorer version และมิติใดในสี่ด้านของ T2 ที่วัด
3. ต้องมีหลักฐานอะไรเพิ่มก่อนกล่าวว่า coordinate สองจุดข้าม stage ระบุสถานที่หรือเซลล์ทางชีววิทยาเดียวกัน?
4. เขียนข้อกล่าวอ้างขอบเขตแคบหนึ่งข้อที่หลักฐานรองรับ และข้อกล่าวอ้างกว้างหนึ่งข้อที่ไม่รองรับ

## ปิดกิจกรรมสำหรับผู้นำ

อย่านำการเปรียบเทียบสมมติมาเสนอเป็นผลหรือแนะนำแบบจำลองผู้ชนะ ชวนผู้เข้าร่วมตรวจสอบ board contract, ดูข้อจำกัดของเครื่องมือชุมชน และบันทึก split กับสมมติฐานของตนเอง เนื้อหานี้เป็นสื่อการศึกษาอิสระ ไม่ใช่คู่มือ scoring อย่างเป็นทางการ
