# Task 2 워크숍: 시공간 예측 이해하기

**75분 · 4–20명 · 코드나 Challenge 데이터 불필요**

단일세포 분석의 기본을 알고 3D 시공간 예측을 처음 접하는 참가자를 위한 자료입니다. 목표는 과제 계약과 증거의 한계를 읽는 것이며 특정 모델을 추천하지 않습니다. 초판 번역에 보조 도구를 사용했으며 한국어 화자의 수정을 환영합니다.

## 준비 및 순서

공식 [과제](https://virtualembryo.ai/challenge/tasks), [데이터](https://virtualembryo.ai/challenge/data), [평가](https://virtualembryo.ai/challenge/evaluation) 페이지를 열고 현재 split을 확인합니다. 모든 사례는 가상입니다. 비공개 데이터나 팀 예측 결과를 공유하지 않습니다.

| 시간 | 활동 |
|---:|---|
| 0–8분 | 예측 결과에 무엇이 포함되어야 하나요? |
| 8–20분 | split을 읽고 보간인지 외삽인지 판단합니다. |
| 20–38분 | 모든 T2 보드가 외삽을 평가한다는 가정을 바로잡습니다. |
| 38–52분 | 분자·세포·공간 증거를 비교합니다. |
| 52–65분 | 발달 단계 사이 좌표의 의미를 검토합니다. |
| 65–75분 | 근거 있는 주장 하나와 근거가 부족한 주장 하나를 씁니다. |

## 연습과 답안 요점

**1. 두 설정.** 가상의 팀은 모든 T2 평가가 학습 범위 이후의 단계 예측이라고 생각합니다. 공식 split 표를 확인하세요. **답:** 전배아 설정은 보간을 평가합니다. 심장 설정에는 보간과 외삽 질문이 모두 있습니다. 정확한 단계는 최신 공식 페이지에서 확인해야 합니다.

**2. 네 평가 차원.** Model A는 발현 변화를 그럴듯하게 예측하지만 점들을 균일한 구름으로 만듭니다. Model B는 모양과 이웃 관계가 그럴듯하지만 발현 변화가 약합니다. **답:** T2는 발현 변화, 세포 상태 분포, 조직 형태/성장 규모, 국소 공간 조직을 각각 25% 반영합니다. 한 차원의 결과가 다른 차원을 증명하지 않습니다. 로컬 pseudo-split은 숨겨진 test 결과를 예측하지 않습니다.

**3. 로컬 좌표계.** 두 단계에서 `(x,y,z)` 값이 같은 세포는 동일한 세포인가요? **답:** 좌표만으로는 알 수 없습니다. 공식 데이터 페이지에 따르면 `spatial_3D`는 배아별 로컬 좌표계이며 단계 간 정합이 되어 있지 않습니다.

## 참가자 메모

선택한 보드의 공개 학습 단계와 예측 대상을 공식 링크와 함께 적습니다. 증거가 네 평가 차원 중 어디에 해당하는지, 단계 간 좌표 대응을 주장하려면 어떤 근거가 필요한지, 한계가 무엇인지 기록합니다. 가상 예시를 실제 결과로 제시하지 마세요.
