# Task 2 ワークショップ：時空間予測を読み解く

**75分 · 4〜20人 · コードやChallengeデータ不要**

single-cellの基礎を知り、3D時空間予測を学び始めた参加者向けです。目的はタスクの仕様と証拠の限界を理解することで、推奨モデルを示すことではありません。初版は支援ツールを用いて翻訳し、日本語話者の修正を歓迎します。

## 準備と進行

公式の[タスク](https://virtualembryo.ai/challenge/tasks)、[データ](https://virtualembryo.ai/challenge/data)、[評価](https://virtualembryo.ai/challenge/evaluation)ページを確認し、現在のsplitを見ます。演習は架空の例のみを使います。個人データやチームの予測結果を共有しません。

| 時間 | 活動 |
|---:|---|
| 0〜8分 | 予測に必要な出力を確認する。 |
| 8〜20分 | splitを読み、補間か外挿かを判断する。 |
| 20〜38分 | すべてのT2評価が外挿だという誤解を修正する。 |
| 38〜52分 | 分子・細胞・空間の証拠を比較する。 |
| 52〜65分 | 発生段階間の座標の意味を検討する。 |
| 65〜75分 | 根拠のある主張と、根拠が足りない主張を一つずつ書く。 |

## 演習と回答の要点

**1. 二つの設定。** 架空のチームは、T2のすべての評価で訓練範囲より後の段階を予測すると考えています。公式splitを確認します。**回答：**全胚設定は補間を評価し、心臓設定には補間と外挿の両方があります。正確な段階は現在の公式ページで確認します。

**2. 四つの評価軸。** Model Aは発現変化を妥当に予測しますが細胞を均一な雲にします。Model Bは形状と近傍が妥当でも発現変化が弱いです。**回答：**T2では発現変化、細胞状態分布、組織形状・成長スケール、局所空間構造が各25%です。一つの軸だけでは他を証明しません。ローカルpseudo-splitはhidden testを予測しません。

**3. ローカル座標。** 二つの段階で`(x,y,z)`が同じ細胞は同一細胞でしょうか。**回答：**座標だけでは分かりません。公式データページによると`spatial_3D`は胚ごとのローカル座標で、段階間の位置合わせはありません。

## 参加者メモ

選んだboardの可視訓練段階と予測対象（公式リンク付き）、証拠が関係する評価軸、段階間の座標対応を主張するために必要な証拠、明記すべき制限を書きます。架空の例を実データの結果として扱わないでください。
