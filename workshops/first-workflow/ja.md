# ピアワークショップ：再現可能なワークフローを始める

**75分 · 4〜20人 · コードやChallengeデータは不要**

Virtual Embryo Challengeの初参加者、学生、共同研究者向けの進行ガイドです。演習はすべて架空の例です。初版翻訳は支援ツールを用いて作成しました。日本語話者からの修正を歓迎します。

## 準備と進行

開始前に公式の[Challenge概要](https://virtualembryo.ai/challenge)、[ルール](https://virtualembryo.ai/challenge/rules)、[コミュニティ資料一覧](https://virtualembryo.ai/challenge/resources)を確認してください。公式ページが優先され、内容は変更される場合があります。個人データ、認証情報、未公開の結果、非公開評価データは共有しないよう伝えます。

| 時間 | 内容 |
|---:|---|
| 0〜8分 | タスクを選び、予測対象を説明する。 |
| 8〜20分 | 資料を探し、前提条件と制限を確認する。 |
| 20〜38分 | ファイル形式チェック、ローカル評価、公式評価を区別する。 |
| 38〜53分 | 架空の外部データ利用案を検討する。 |
| 53〜66分 | 実行を再現するための記録を挙げる。 |
| 66〜75分 | 次の小さな行動と提出前チェックを決める。 |

## 参加者ワークシート

1. 具体的な困りごとに合う資料を一つ探す。何に答え、どんな制限が書かれているか。
2. Validatorが`PASS`を返し、pseudo-splitではModel Aが高得点だった。この結果は正しい正規化、外部データの適格性、hidden testでの優位を証明するか。追加で必要な証拠は何か。
3. 公開データを使う前に、出典・版、ライセンス、発生段階・組織、タスクとの関連、適用される公式ルール、保存するprovenanceを記録する。
4. 実行の再現には、コード版、環境、設定、random seed、コマンド、利用が認められた入力、評価したファイルを記録する。

## 進行役向けの回答要点

`PASS`が示すのは実装されたチェックだけです。ローカル比較は選んだsplitとprotocolに限られ、hidden leaderboardを単独で予測しません。データが公開されているだけでは利用資格は証明されません。ルールやライセンスが不明なら利用を止めます。ログ、hash、transcriptは監査に役立ちますが、単独で完全な遵守を証明しません。

**締めくくり：**各自が小さな次の行動、確認する公式ページ、提出前に解決する不確実点を一つ書きます。独立したコミュニティ資料であり、公式イベントや戦略助言ではありません。
