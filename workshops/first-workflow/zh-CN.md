# 同伴工作坊：启动可复现的工作流程

**75 分钟 · 4–20 人 · 无需编程或 Challenge 数据**

面向首次参加 Virtual Embryo Challenge 的参与者、学生和合作者的可直接使用的主持指南。练习情境均为虚构。首版翻译使用辅助工具，欢迎中文母语者提出修订。

## 准备与流程

课前查看官方的[Challenge 页面](https://virtualembryo.ai/challenge)、[规则](https://virtualembryo.ai/challenge/rules)和[社区资源](https://virtualembryo.ai/challenge/resources)。官方页面优先，内容可能变化。请参与者不要分享私人数据、凭证、未发表结果或隐藏评测文件。

| 时间 | 活动 |
|---:|---|
| 0–8 分钟 | 选择一项任务，用自己的话说明预测目标。 |
| 8–20 分钟 | 查找一个资源，并检查其前提条件与局限。 |
| 20–38 分钟 | 区分文件格式检查、本地评估和官方评估。 |
| 38–53 分钟 | 讨论虚构的外部数据使用提议。 |
| 53–66 分钟 | 列出复现一次运行所需的记录。 |
| 66–75 分钟 | 写下下一步行动和一项提交前检查。 |

## 参与者练习

1. 为一个具体问题找资源。它回答什么问题？作者声明了什么限制？
2. 验证器显示 `PASS`，本地划分上模型 A 得分较高。这能证明表达值已正确归一化、外部数据合规，或 A 会在隐藏测试中排名更高吗？还缺什么证据？
3. 使用公共数据前，记录来源和版本、许可证、发育阶段与组织、任务相关性、适用的官方规则以及要保存的来源信息。
4. 为复现运行，记录代码版本、环境、配置、随机种子、命令、允许使用的输入和实际评分文件。

## 主持人答案要点

`PASS` 只表示该验证器执行的检查通过。本地比较只说明所选数据划分和协议下的结果，不能单独预测隐藏榜单。数据公开不等于使用合规；若规则或许可证不清楚，应先暂停。日志、哈希和运行记录有助于审计，但都不能单独证明完全遵守规则。

**结束：**每个人写下一项小行动、将查看的官方页面，以及一个提交前要解决的不确定问题。本材料是独立社区资源，不代表官方活动或策略建议。
