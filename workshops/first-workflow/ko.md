# 동료 워크숍: 재현 가능한 워크플로 시작하기

**75분 · 4–20명 · 코드나 Challenge 데이터 불필요**

Virtual Embryo Challenge에 처음 참여하는 사람, 학생, 협력자를 위한 진행자용 안내서입니다. 모든 연습은 가상 시나리오를 사용합니다. 초판 번역은 보조 도구를 이용했으며 한국어 화자의 수정을 환영합니다.

## 준비 및 진행 순서

시작 전에 공식 [Challenge 소개](https://virtualembryo.ai/challenge), [규칙](https://virtualembryo.ai/challenge/rules), [커뮤니티 자료](https://virtualembryo.ai/challenge/resources)를 확인하세요. 공식 페이지가 우선이며 내용은 바뀔 수 있습니다. 참가자에게 비공개 데이터, 자격 증명, 미공개 결과, 숨겨진 평가 파일을 공유하지 말라고 안내하세요.

| 시간 | 활동 |
|---:|---|
| 0–8분 | 과제를 고르고 예측 대상을 설명합니다. |
| 8–20분 | 자료를 찾아 전제 조건과 한계를 확인합니다. |
| 20–38분 | 파일 형식 검사, 로컬 평가, 공식 평가를 구분합니다. |
| 38–53분 | 가상의 외부 데이터 사용 제안을 검토합니다. |
| 53–66분 | 실행을 재현하는 데 필요한 기록을 적습니다. |
| 66–75분 | 다음 행동 하나와 제출 전 점검 하나를 정합니다. |

## 참가자 워크시트

1. 구체적인 필요에 맞는 자료를 하나 찾으세요. 어떤 질문에 답하며 어떤 한계를 밝히나요?
2. Validator가 `PASS`를 반환하고 pseudo-split에서 Model A가 앞섭니다. 이것이 정규화, 외부 데이터의 적격성, 숨겨진 test에서의 우위를 증명하나요? 어떤 근거가 더 필요할까요?
3. 공개 데이터를 쓰기 전에 출처와 버전, 라이선스, 발달 단계와 조직, 과제 관련성, 적용되는 공식 규칙, 보존할 provenance를 적으세요.
4. 실행 재현을 위해 코드 버전, 환경, 설정, random seed, 명령어, 허용된 입력, 평가한 파일을 기록하세요.

## 진행자 답안 요점

`PASS`는 구현된 검사만 통과했다는 뜻입니다. 로컬 비교는 선택한 split과 protocol에 대한 결과일 뿐 숨겨진 순위를 예측하지 않습니다. 공개 데이터라고 해서 사용이 허용되는 것은 아닙니다. 규칙이나 라이선스가 불분명하면 사용을 멈추세요. 로그, 해시, transcript는 감사를 돕지만 그 자체로 완전한 규칙 준수를 증명하지 않습니다.

**마무리:** 각자 작은 다음 단계, 확인할 공식 페이지, 제출 전에 해결할 불확실성을 씁니다. 독립적인 커뮤니티 자료이며 공식 행사나 전략 조언이 아닙니다.
