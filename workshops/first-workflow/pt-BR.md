# Oficina entre pares: comece um fluxo de trabalho reproduzível

**75 minutos · 4–20 pessoas · sem código nem dados do Challenge**

Guia pronto para facilitar para novos participantes, estudantes e colaboradores do Virtual Embryo Challenge. Todos os cenários são fictícios. Esta tradução inicial teve ajuda de ferramentas; sugestões de falantes nativos são bem-vindas.

## Preparação e agenda

Antes da oficina, consulte as páginas oficiais do [Challenge](https://virtualembryo.ai/challenge), das [regras](https://virtualembryo.ai/challenge/rules) e dos [recursos da comunidade](https://virtualembryo.ai/challenge/resources). Elas são a fonte de referência e podem mudar. Peça que ninguém compartilhe dados privados, credenciais, resultados inéditos ou arquivos de avaliação ocultos.

| Minutos | Atividade |
|---:|---|
| 0–8 | Escolher uma tarefa e explicar o alvo da previsão. |
| 8–20 | Encontrar um recurso e conferir requisitos e limitações. |
| 20–38 | Separar validação de formato, avaliação local e avaliação oficial. |
| 38–53 | Analisar uma proposta fictícia de dados externos. |
| 53–66 | Listar registros necessários para reproduzir uma execução. |
| 66–75 | Definir uma próxima ação e uma checagem antes do envio. |

## Folha dos participantes

1. Encontre um recurso para uma necessidade concreta. Que pergunta ele responde? Que limite informa?
2. Um validador mostra `PASS` e um pseudo-split favorece o Modelo A. Isso comprova normalização correta, elegibilidade dos dados externos ou melhor resultado no teste oculto? Que evidência falta?
3. Antes de usar dados públicos, registre fonte e versão, licença, estágio e tecido, relevância para a tarefa, regra oficial aplicável e proveniência a guardar.
4. Para reproduzir uma execução, registre revisão do código, ambiente, configuração, semente aleatória, comando, entradas permitidas e arquivo avaliado.

## Respostas para facilitação

`PASS` confirma apenas as verificações implementadas. A comparação local se limita ao split e protocolo escolhidos; não prevê sozinha o ranking oculto. Ser público não torna o dado automaticamente elegível. Se houver dúvida sobre regra ou licença, interrompa o uso e esclareça. Logs, hashes e transcrições ajudam na auditoria, mas nenhum deles prova sozinho conformidade completa.

**Encerramento:** cada pessoa registra um passo pequeno, uma página oficial para consultar e uma incerteza a resolver antes do envio. Material independente da comunidade, não é evento oficial nem aconselhamento de estratégia.
