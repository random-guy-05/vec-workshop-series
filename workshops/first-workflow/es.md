# Taller entre pares: empieza un flujo de trabajo reproducible

**75 minutos · 4–20 personas · sin programación ni datos del Challenge**

Guía lista para facilitar a participantes nuevos, estudiantes y colaboradores. La sesión usa escenarios ficticios. Traducción inicial asistida por herramientas; se agradecen correcciones de hablantes nativos.

## Preparación y agenda

Antes del taller, revisa el [Challenge](https://virtualembryo.ai/challenge), las [reglas](https://virtualembryo.ai/challenge/rules) y los [recursos comunitarios](https://virtualembryo.ai/challenge/resources). Esas páginas oficiales prevalecen y pueden cambiar. Pide a las parejas que no compartan datos privados, credenciales, resultados inéditos ni archivos ocultos.

| Minutos | Actividad |
|---:|---|
| 0–8 | Elegir una tarea y describir su objetivo. |
| 8–20 | Buscar un recurso y revisar sus requisitos y límites. |
| 20–38 | Distinguir validación de formato, evaluación local y evaluación oficial. |
| 38–53 | Evaluar una propuesta ficticia de datos externos. |
| 53–66 | Elegir qué registrar para reproducir una ejecución. |
| 66–75 | Escribir el siguiente paso y una comprobación. |

## Hoja de trabajo

1. Encuentra un recurso para una necesidad concreta. ¿Qué pregunta responde y qué limitación declara?
2. Un validador dice `PASS` y una división local favorece al Modelo A. ¿Eso demuestra que los datos están normalizados, que la fuente externa es elegible o que A ganará en el test oculto? Explica qué evidencia falta.
3. Antes de usar un conjunto público, anota fuente y versión, licencia, etapa y tejido, relación con la tarea, regla oficial aplicable y procedencia que guardarás.
4. Para reproducir una ejecución, registra revisión del código, entorno, configuración, semilla, comando, entradas permitidas y archivo evaluado.

## Claves para facilitar

`PASS` solo confirma las comprobaciones implementadas. Una comparación local habla de esa división y ese protocolo; no predice por sí sola la clasificación oculta. Que un conjunto sea público no prueba que su uso sea elegible. Detén el uso si la regla o licencia no está clara. Registros, hashes y transcripciones ayudan a auditar, pero ninguno demuestra por sí solo el cumplimiento completo.

**Cierre:** cada persona escribe una acción pequeña, una fuente oficial que consultará y una incertidumbre que resolverá. No es un evento oficial ni una recomendación de estrategia.
