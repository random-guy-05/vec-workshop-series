# Task 3 工作坊：预测扰动响应

**75 分钟 · 4–20 人 · 无需代码或 Challenge 数据**

帮助参与者理解条件性敲除预测。核心是区分扰动造成的变化与野生型（WT）背景。本工作坊不提出生物机制或建模方案。首版翻译使用辅助工具，欢迎母语者修订。

## 准备与流程

查看官方[任务](https://virtualembryo.ai/challenge/tasks)、[数据](https://virtualembryo.ai/challenge/data)和[规则](https://virtualembryo.ai/challenge/rules)，确认当前 split。所有数字和名称均为虚构；不使用隐藏目标的测量结果。

| 时间 | 活动 |
|---:|---|
| 0–8 分钟 | 明确预测中应该改变的是什么。 |
| 8–20 分钟 | 找出训练、验证与测试条件。 |
| 20–38 分钟 | 将扰动与匹配的 WT 比较。 |
| 38–52 分钟 | 把常见失败对应到响应指标。 |
| 52–65 分钟 | 审查虚构的外部数据提议。 |
| 65–75 分钟 | 写出一个有证据支持的说法及其限制。 |

## 练习 1：背景与响应

一个通用特征的虚构归一化数值：WT = 10.0；扰动下的模型 A = 10.1；模型 B = 7.0。哪个模型预测的 WT 差异更大？

**答案：**A 预测的变化接近零；B 预测的下降更大。此例不说明哪种方向在生物学上正确。评估关注相对于 WT 的响应；只复制 WT 背景是不够的。

## 练习 2：四类响应指标

匹配失败类型：(a) 正确的基因朝相反方向变化；(b) 方向正确但幅度太小；(c) 错误的基因发生变化；(d) 细胞比例坍塌。**答案：**分别对应响应方向、响应幅度、响应基因恢复、细胞状态分布。每项指标提供不同证据。

## 练习 3：外部数据合规性

同事提出使用相近发育阶段、敲除相关基因的公共数据。使用前需检查来源和版本、等位基因/基因型、阶段、许可证、任务相关性、现行规则和披露要求。相关基因或产生相似表型的扰动也可能落入受保护条件。若资格不清楚，应暂停并询问组织者。

## 参与者练习单

1. 从官方页面找出训练扰动、验证目标和隐藏测试目标。
2. 计算示例中的 `扰动 − WT`；差值揭示了什么？
3. 将练习 2 的失败对应到具体指标。
4. 若要提出真实生物学结论，还缺哪些证据？

这些数字只用于教学，不是 VEC 数据。本指南是独立社区材料，不是官方评估说明或策略建议。
