# Task 3 பணிமனை: perturbation பதிலை முன்கணித்தல்

**75 நிமிடங்கள் · 4–20 பங்கேற்பாளர்கள் · குறியீடோ Challenge தரவோ தேவையில்லை**

conditional-knockout முன்கணிப்புப் பணியைப் பற்றி பகுத்தறிய பங்கேற்பாளர்களுக்கு இந்த அமர்வு உதவுகிறது. perturbation விளைவையும் wild-type பின்னணியையும் வேறுபடுத்துவதே முக்கியக் கற்றல் இலக்கு. இது உயிரியல் செயல்முறையையோ modeling recipe-யையோ முன்மொழியாது.

> இது இயந்திர உதவியுடன் உருவாக்கிய முதல் மொழிபெயர்ப்பு; தாய்மொழிப் பேசுவோரின் திருத்தங்கள் வரவேற்கப்படுகின்றன. [ஆங்கில மூல உரை](en.md).

## தயாரிப்பு

அதிகாரப்பூர்வமான [பணி விளக்கங்கள்](https://virtualembryo.ai/challenge/tasks), [தரவு schema](https://virtualembryo.ai/challenge/data), மற்றும் தற்போதைய [விதிகள்](https://virtualembryo.ai/challenge/rules) ஆகியவற்றைத் திறக்கவும். காகிதம் கொண்டு வரவும் அல்லது இந்த வழிகாட்டியைப் பகிரவும். பயிற்சிகளில் கற்பனை எண்களும் பொதுவான feature பெயர்களும் பயன்படுத்தப்படுகின்றன. hidden-target அளவீடுகளைப் பயன்படுத்த வேண்டாம். அதிகாரப்பூர்வப் பக்கங்களே முன்னுரிமை பெறும்; அவை மாறக்கூடும்.

## பயிற்சி 1 — பின்னணி மற்றும் பதில்

கீழுள்ளவை பொதுவான feature ஒன்றிற்கான கற்பனை normalized toy values. இவை உண்மையான VEC கவனிப்புகள் அல்ல.

| Condition | கற்பனை மதிப்பு |
|---|---:|
| matched wild type | 10.0 |
| perturbation, Model A | 10.1 |
| perturbation, Model B | 7.0 |

எந்த மாதிரி wild-type பின்னணியைப் பிரதிபலிக்கிறது, எது பெரிய மாற்றத்தை முன்கணிக்கிறது என்று ஜோடிகளிடம் கேளுங்கள். absolute expression ஒப்பீடு மட்டும் wild type-ஐ அப்படியே நகலெடுக்கும் மாதிரியை ஏன் சாதகமாக்கலாம் என்றும் கேளுங்கள்.

### விடைக்குறிப்பு

Model A wild-type மதிப்புக்கு அருகில் இருப்பதால், அதன் முன்கணிக்கப்பட்ட மாற்றம் கிட்டத்தட்ட பூஜ்யம். Model B பெரிய குறைவை முன்கணிக்கிறது. எந்தத் திசை உயிரியல் ரீதியாகச் சரி என்பதை இந்த toy எடுத்துக்காட்டு கூறாது; கவனிக்கப்பட்ட perturbation response அதனை நிர்ணயிக்கும். Challenge response-ஐ wild type-உடன் ஒப்பிட்டு மதிப்பிடுகிறது; ஆகவே பொதுவான பின்னணியைப் பொருத்துவது மட்டும் போதாது.

## பயிற்சி 2 — response பற்றிய நான்கு கேள்விகள்

அதிகாரப்பூர்வ T3 metric-கள் response-gene recovery, response direction, response magnitude, cell-state distribution ஆகியவற்றைக் கொண்டுள்ளன. ஒவ்வொரு கற்பனைத் தோல்வியையும் metric-உடன் பொருத்துங்கள்: (a) சரியான genes எதிர்திசையில் மாறுகின்றன; (b) திசை சரி, ஆனால் விளைவு மிகச் சிறியது; (c) தவறான genes-இல் பெரிய மாற்றங்கள்; (d) cell-state விகிதங்கள் சரிகின்றன.

### விடைக்குறிப்பு

(a) response direction; (b) response magnitude; (c) response-gene recovery; (d) cell-state distribution. ஒவ்வொரு metric-மும் வேறுபட்ட சான்று. ஒன்றில் நல்ல மதிப்பு மற்றவை நல்லவை என்பதை நிரூபிக்காது.

## பயிற்சி 3 — வெளித் தரவு ஆய்வு

ஒத்த stage-இல் தொடர்புடைய gene-க்கான knockout கொண்ட பொது dataset ஒன்றை சக ஊழியர் பரிந்துரைக்கிறார். பயன்படுத்துவதற்கு முன் சரிபார்க்க வேண்டியவை: சரியான gene/allele மற்றும் genotype, stage, source மற்றும் release, license, பணிக்கான தொடர்பு, தற்போதைய held-out விதிகள், disclosure தேவைகள். தீர்க்கப்படாத எந்த விவரம் பயன்பாட்டை நிறுத்தச் செய்ய வேண்டும்?

### விடைக்குறிப்பு

தற்போதைய விதிகளுடன் சரியான source, perturbation, stage ஆகியவற்றை ஒப்பிட்டு சரிபார்க்கும் வரை குழு நிறுத்த வேண்டும். தொடர்புடைய allele அல்லது phenocopy பாதுகாக்கப்பட்ட held-out condition-க்குள் வரலாம்; பொது URL இருப்பது eligibility-ஐ நிரூபிக்காது. விதிகளில் உள்ள தெளிவான வரம்பைப் பின்பற்றவும்; பொருத்தம் தெளிவில்லாவிட்டால் முன்கூட்டியே organizers-ஐக் கேளுங்கள்.

## பங்கேற்பாளர் பணித்தாள்

1. தற்போதைய அதிகாரப்பூர்வ Task 3 பக்கத்தில் வெளியிடப்பட்ட perturbation training example, validation target, hidden test target ஆகியவற்றைப் பெயரிடவும்.
2. ஒவ்வொரு மாதிரிக்கும் `perturbation − matched wild type` கணக்கிடவும். absolute மதிப்புகள் மறைத்ததை difference எவ்வாறு வெளிப்படுத்தியது?
3. பயிற்சி 2-இன் ஒவ்வொரு தோல்வியையும் metric-உடன் பொருத்தவும்.
4. வெளிப்புற perturbation dataset தகுதியானது, வெளிப்படுத்தப்பட வேண்டியது என்று கருதுவதற்கு முன் தேவைப்படும் சான்றுகளைப் பட்டியலிடவும்.
5. toy எடுத்துக்காட்டு ஆதரிக்கும் ஒரு கூற்றையும் ஆதரிக்காத உயிரியல் கூற்றையும் எழுதவும்.

## வழிநடத்துநரின் நிறைவு

கற்பனை மதிப்புகளிலிருந்து உண்மையான உயிரியல் முடிவுகளை ஊகிக்க வேண்டாம். எந்தப் பகுப்பாய்விலும் perturbation contrast, matched control, genotype, stage, source provenance ஆகியவற்றைத் தெளிவாக வைக்கச் சொல்லுங்கள். இது சுயாதீனக் கல்வி உள்ளடக்கம்; அதிகாரப்பூர்வ evaluation வழிகாட்டி அல்ல.
