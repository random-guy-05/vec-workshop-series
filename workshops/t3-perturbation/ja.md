# Task 3 ワークショップ：摂動応答を予測する

**75分 · 4〜20人 · コードやChallengeデータ不要**

条件付きノックアウト予測を学ぶセッションです。中心となる目標は、摂動の効果と野生型（WT）の背景を区別することです。生物学的機序や推奨モデルを提示するものではありません。初版は支援ツールを用いて翻訳し、日本語話者の修正を歓迎します。

## 準備と進行

公式の[タスク](https://virtualembryo.ai/challenge/tasks)、[データ](https://virtualembryo.ai/challenge/data)、[ルール](https://virtualembryo.ai/challenge/rules)を開き、現在のsplitを確認します。数値と遺伝子名はすべて架空です。hidden targetの実測値は使いません。

| 時間 | 内容 |
|---:|---|
| 0〜8分 | 予測で何が変化すべきか定義する。 |
| 8〜20分 | 訓練・検証・テスト条件を確認する。 |
| 20〜38分 | 摂動と対応するWTを比較する。 |
| 38〜52分 | 失敗例と応答指標を対応づける。 |
| 52〜65分 | 架空の外部データ案を審査する。 |
| 65〜75分 | 根拠のある主張と限界を書く。 |

## 演習1 — 背景と応答

一般的な特徴量の架空の正規化値：WT = 10.0、摂動下のModel A = 10.1、Model B = 7.0。WTからの変化が大きいのはどちらでしょうか。

**回答：**Aの変化はほぼゼロ、Bは大きな低下を予測します。この例は生物学的に正しい方向を示しません。評価対象はWTに対する応答で、WT背景をそのまま写すだけでは不十分です。

## 演習2 — 四つの応答指標

(a) 正しい遺伝子が逆方向に変化、(b) 方向は正しいが変化量が小さい、(c) 別の遺伝子が変化、(d) 細胞構成比が崩れる。対応する指標は？ **回答：**順に応答方向、応答量、応答遺伝子の回復、細胞状態分布です。それぞれ別の証拠を示します。

## 演習3 — 外部データの適格性

同僚が近い発生段階の関連遺伝子ノックアウトの公開データを提案します。利用前に出典・版、アレル/遺伝子型、段階、ライセンス、タスクとの関連、最新ルール、開示方法を確認します。関連アレルや類似表現型も保護対象となる場合があります。不明なら利用を止めて主催者に確認します。

## 参加者メモ

公式ページから訓練用摂動、検証対象、hidden test対象を確認します。例の `摂動 − WT` を計算し、差から分かること、演習2の失敗と指標、実際の生物学的主張に不足している証拠を記録します。数値は教材用で、VEC実測値ではありません。
