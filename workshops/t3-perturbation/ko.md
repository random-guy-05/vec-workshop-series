# Task 3 워크숍: perturbation 반응 예측하기

**75분 · 4–20명 · 코드나 Challenge 데이터 불필요**

조건부 knockout 예측을 이해하기 위한 세션입니다. 핵심은 perturbation 효과와 야생형(WT) 배경을 구분하는 것입니다. 생물학적 기전이나 특정 모델을 권하지 않습니다. 초판 번역은 보조 도구를 이용했으며 한국어 화자의 수정을 환영합니다.

## 준비 및 순서

공식 [과제](https://virtualembryo.ai/challenge/tasks), [데이터](https://virtualembryo.ai/challenge/data), [규칙](https://virtualembryo.ai/challenge/rules)을 열고 현재 split을 확인합니다. 예시 숫자와 이름은 가상이며 숨겨진 목표의 측정값은 사용하지 않습니다.

| 시간 | 활동 |
|---:|---|
| 0–8분 | 예측에서 무엇이 바뀌어야 하는지 정의합니다. |
| 8–20분 | 훈련, 검증, 테스트 조건을 확인합니다. |
| 20–38분 | perturbation을 짝지어진 WT와 비교합니다. |
| 38–52분 | 실패 유형을 반응 지표에 연결합니다. |
| 52–65분 | 가상의 외부 데이터 제안을 검토합니다. |
| 65–75분 | 근거 있는 주장과 한계를 씁니다. |

## 연습 1 — 배경과 반응

일반 특성에 대한 가상 정규화 값: WT = 10.0, perturbation 상태 Model A = 10.1, Model B = 7.0. 어떤 모델이 WT에 비해 더 큰 변화를 예측하나요?

**답:** A는 변화가 거의 없고 B는 더 큰 감소를 예측합니다. 이 예시는 생물학적으로 올바른 방향을 알려주지 않습니다. 평가는 WT 대비 반응을 다루므로 WT 배경을 복사하는 것만으로는 충분하지 않습니다.

## 연습 2 — 네 가지 반응 지표

(a) 올바른 유전자가 반대 방향으로 변함, (b) 방향은 맞지만 크기가 너무 작음, (c) 잘못된 유전자가 변함, (d) 세포 상태 비율이 무너짐. **답:** 각각 반응 방향, 반응 크기, 반응 유전자 복구, 세포 상태 분포에 해당합니다. 서로 다른 증거를 나타냅니다.

## 연습 3 — 외부 데이터 적격성

동료가 비슷한 발달 단계의 관련 유전자 knockout 공개 데이터를 제안합니다. 사용 전 출처/버전, allele/genotype, 단계, 라이선스, 과제 관련성, 최신 규칙, 공개 사항을 확인합니다. 관련 allele이나 유사한 phenotype도 보호 대상에 포함될 수 있습니다. 불분명하면 사용을 멈추고 주최자에게 문의하세요.

## 참가자 워크시트

공식 페이지에서 훈련 perturbation, 검증 대상, 숨겨진 test 대상을 적습니다. 예시의 `perturbation − WT`를 계산하고 차이가 보여 주는 것을 설명합니다. 연습 2의 실패와 지표를 연결하고 실제 생물학적 주장을 위해 필요한 추가 근거를 적습니다. 예시 값은 교육용이지 VEC 데이터가 아닙니다.
