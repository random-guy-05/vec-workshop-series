# เวิร์กช็อป Task 3: ทำนายการตอบสนองต่อ perturbation

**75 นาที · ผู้เข้าร่วม 4–20 คน · ไม่ต้องใช้โค้ดหรือข้อมูล Challenge**

เซสชันนี้ช่วยให้คิดเกี่ยวกับ Task การพยากรณ์ conditional knockout เป้าหมายการเรียนรู้หลักคือแยกผลของ perturbation ออกจากพื้นหลัง wild type เซสชันนี้ไม่ได้เสนอทั้งกลไกทางชีววิทยาหรือสูตรสร้างแบบจำลอง

> ฉบับแปลแรกนี้ใช้เครื่องมือช่วยแปลและเปิดรับการแก้ไขจากเจ้าของภาษา [ต้นฉบับภาษาอังกฤษ](en.md)

## เตรียมการ

เปิดหน้าอย่างเป็นทางการเกี่ยวกับ[คำอธิบาย Task](https://virtualembryo.ai/challenge/tasks), [schema ข้อมูล](https://virtualembryo.ai/challenge/data), และ[กฎปัจจุบัน](https://virtualembryo.ai/challenge/rules) เตรียมกระดาษหรือแชร์คู่มือนี้ แบบฝึกหัดใช้ตัวเลขสมมติและชื่อคุณลักษณะทั่วไป ห้ามใช้ค่าของเป้าหมายที่ซ่อนไว้ หน้าอย่างเป็นทางการมีอำนาจอ้างอิงและอาจเปลี่ยนได้

## แบบฝึกหัด 1 — พื้นหลังกับการตอบสนอง

ค่าต่อไปนี้เป็นค่า toy แบบ normalized ที่แต่งขึ้นสำหรับคุณลักษณะทั่วไป ไม่ใช่ผลสังเกตของ VEC

| Condition | ค่าสมมติ |
|---|---:|
| matched wild type | 10.0 |
| perturbation, Model A | 10.1 |
| perturbation, Model B | 7.0 |

ถามแต่ละคู่ว่า model ใดทำซ้ำค่าพื้นหลัง wild type และ model ใดทำนายการเปลี่ยนแปลงมากกว่า จากนั้นถามว่าทำไมการเทียบ absolute expression อย่างเดียวอาจเอื้อให้ model ที่เพียงคัดลอก wild type

### เฉลย

Model A ใกล้ค่า wild type จึงทำนายการเปลี่ยนแปลงเกือบเป็นศูนย์ Model B ทำนายการลดลงที่มากกว่า ตัวอย่าง toy นี้ไม่ได้บอกว่าทิศทางใดถูกต้องทางชีววิทยา; response ของ perturbation ที่สังเกตได้เป็นตัวกำหนด การประเมิน Challenge วัด response เทียบกับ wild type จึงไม่เพียงพอที่จะจับคู่แค่พื้นหลังร่วม

## แบบฝึกหัด 2 — คำถาม response สี่ข้อ

metric T3 อย่างเป็นทางการครอบคลุมการกู้คืน response gene, ทิศทาง response, ขนาด response และการกระจาย cell-state ให้แต่ละคู่จับคู่ความล้มเหลวสมมติกับ metric: (a) gene ถูกแต่ทิศทางผิด; (b) ทิศทางถูกแต่ผลเล็กเกินไป; (c) gene ที่เปลี่ยนแรงเป็นคนละ gene; (d) สัดส่วน cell-state ยุบตัว

### เฉลย

(a) ทิศทาง response; (b) ขนาด response; (c) การกู้คืน response gene; (d) การกระจาย cell-state แต่ละ metric ให้หลักฐานคนละด้าน ค่า metric หนึ่งที่ดีไม่ได้พิสูจน์ว่าผลด้านอื่นดีด้วย

## แบบฝึกหัด 3 — ตรวจสอบข้อมูลภายนอก

เพื่อนร่วมงานเสนอ dataset สาธารณะจาก stage ใกล้เคียงที่มี knockout ของ gene ที่เกี่ยวข้อง ให้กลุ่มระบุการตรวจสอบก่อนใช้: gene/allele และ genotype ที่แน่นอน, stage, แหล่งและ release, license, ความเกี่ยวข้องกับ Task, กฎ held-out ปัจจุบัน และข้อกำหนดการเปิดเผย ข้อเท็จจริงใดที่ยังไม่คลี่คลายและควรทำให้หยุดใช้?

### เฉลย

กลุ่มควรพักการใช้จนกว่าจะตรวจแหล่ง perturbation และ stage ที่แน่นอนเทียบกับกฎปัจจุบันได้ allele ที่เกี่ยวข้องหรือ phenocopy อาจอยู่ใน condition held-out ที่ได้รับการคุ้มครอง URL สาธารณะไม่ได้พิสูจน์ eligibility ให้ปฏิบัติตามขอบเขตที่ระบุในกฎ และถาม organizer ล่วงหน้าหากความตรงกันยังคลุมเครือ

## ใบงานผู้เข้าร่วม

1. จากหน้า Task 3 อย่างเป็นทางการปัจจุบัน ระบุ perturbation training example ที่เผยแพร่, validation target และ hidden test target
2. คำนวณ `perturbation − matched wild type` สำหรับแต่ละ model ในตัวอย่างสมมติ ความต่างเผยอะไรที่ค่า absolute ปิดบัง?
3. จับคู่ความล้มเหลวแต่ละข้อในแบบฝึกหัด 2 กับ metric
4. เขียนหลักฐานที่ต้องมี ก่อนพิจารณาว่า dataset perturbation ภายนอกใช้ได้และเปิดเผยได้
5. เขียนข้อกล่าวอ้างหนึ่งข้อที่ตัวอย่าง toy รองรับ และข้อกล่าวอ้างทางชีววิทยาหนึ่งข้อที่ไม่รองรับ
